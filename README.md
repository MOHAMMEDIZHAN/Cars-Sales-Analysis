# 🚗 Car Sales Analysis 

## 📌 Overview

This project analyzes car sales data using **Excel and Power BI** to uncover insights into sales performance, customer behavior, and product segmentation.

---

## 📂 Datasets

* **Cars** – vehicle details and price segmentation
* **Customers** – customer demographics and age segmentation
* **Sales** – transaction data and customer loyalty classification

---

## 🛠 Tools Used

* Microsoft Excel
* Power BI

---

## 🔗 Data Modeling

* Cars → Sales (One-to-Many via `Car_ID`)
* Customers → Sales (One-to-Many via `Customer_ID`)

---

## 📊 Dashboard Highlights

* Brand-wise and segment-wise sales analysis
* Customer age and loyalty insights
* Engine type and inventory distribution
